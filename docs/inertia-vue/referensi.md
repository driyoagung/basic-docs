# Referensi

Berikut sumber resmi dan komunitas yang menjadi dasar penulisan dokumentasi ini. Pelajari untuk pemahaman lebih mendalam.

## Dokumentasi Resmi

- [Inertia.js Docs](https://inertiajs.com) — dokumentasi resmi Inertia.js (server & client adapter)
- [Laravel Docs](https://laravel.com/docs) — dokumentasi resmi Laravel 11
- [Vue.js Docs](https://vuejs.org) — dokumentasi resmi Vue 3
- [Vite](https://vitejs.dev) — bundler dan dev server yang digunakan Laravel
- [Tailwind CSS](https://tailwindcss.com) — framework utility-first CSS

## Library & Package

- [Ziggy](https://github.com/tightenco/ziggy) — helper `route()` Laravel di JavaScript
- [@inertiajs/vue3](https://www.npmjs.com/package/@inertiajs/vue3) — adapter Inertia untuk Vue 3
- [Headless UI Vue](https://headlessui.com/v1/vue) — komponen UI accessible tanpa styling
- [Pinia](https://pinia.vuejs.org) — state management resmi Vue
- [VueUse](https://vueuse.org) — koleksi composable utility untuk Vue 3
- [Heroicons Vue](https://github.com/tailwindlabs/heroicons) — ikon SVG dari tim Tailwind
- [Lucide Vue Next](https://lucide.dev) — alternatif ikon populer
- [PrimeVue](https://primevue.org) — library komponen UI lengkap
- [Flowbite](https://flowbite.com) — komponen Tailwind siap pakai

## Komunitas & Tutorial

- [Laravel Indonesia](https://laravel.co.id) — komunitas Laravel Indonesia
- [Laravel News](https://laravel-news.com) — berita dan tutorial Laravel
- [Vue School](https://vueschool.io) — kursus Vue.js
