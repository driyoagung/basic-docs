# ⚙️ Bagian 7 — Pemrograman di Database & Skala

> 🎯 **Tujuan Bagian:** mengenal logika di dalam database dan strategi ketika data serta koneksi bertambah.

## 📖 Bab di Bagian Ini

| Bab | Judul | Fokus |
|---|---|---|

## ✅ Setelah Bagian Ini Anda Bisa

- Membuat view dan materialized view
- Menulis function dan procedure dengan PL/pgSQL
- Memakai trigger untuk `updated_at` dan audit
- Memilih antara logika di database vs aplikasi
- Memahami partisi dan connection pooling
