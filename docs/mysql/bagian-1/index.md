## ✅ Hasil yang Diharapkan

Setelah menyelesaikan bagian ini, Anda mampu:

- menjelaskan perbedaan data, database, dan DBMS;
- memilih SQL atau NoSQL berdasarkan kebutuhan;
- membaca istilah tabel, baris, kolom, primary key, dan foreign key;
- menjalankan MySQL 8.x lewat Docker atau instalasi lokal;
- masuk ke MySQL CLI dan membuat database latihan `toko`.

::: tip 💡 Tips
Jangan menunda instalasi sampai Bab 4. Siapkan MySQL lebih awal agar setiap contoh SQL di bab berikutnya bisa langsung Anda ketik dan jalankan.
:::
